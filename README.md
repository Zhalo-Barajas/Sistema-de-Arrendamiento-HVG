# Sistema de Arrendamiento HVG

Prototipo de sistema de arrendamiento para inmuebles y servicios escrito en PHP 8.4. Intencionado para su uso conjunto con otros módulos del _Sistema ERP Doquimta_.
<hr/>
<h3>¿Qué contiene este repositorio?</h3>
<hr/>
<ul>
  <li>Sistema de cotización, arrendamiento y posventa de inmuebles y servicios bajo un paradigma orientado a la definición de conceptos e insumos de manera recursiva.</li>
  <li>Seguimiento de Ingresos y Reservaciones con calendario interactivos.</li>
  <li>Capacidad de establecer qué conceptos son incluidos de base a un inmueble/servicio, así como la capacidad de ser editados extraordinariamente por cotización.</li>
  <li>Capacidad de establecer margenes fijos y flotantes de ganancia para inmuebles, servicios y conceptos.</li>
  <li>Integración de administración de servicios bajo un esquema de tres categorías.</li>
  <li>Generación de documentos PDF a través de DOMPDF.</li>
  <li>Comunicación con la API de mensajería <i>UltraMsg</i> para el envío de documentos y mensajes por medio de WhatsApp.</li>
  <li>Seguimiento de pagos y atención al cliente por medio de enlace a módulo de comunicación por WhatsApp.</li>
</ul>
